# الخطط الذكية — متوسطة لبيد بن ربيعة 1448هـ

بوابة متابعة الخطط والبرامج المدرسية، تُنشر على GitHub Pages وتحفظ بياناتها في Supabase.

- **الاستعراض:** متاح للجميع دون دخول.
- **الإضافة والحذف:** من الواجهة نفسها بعد «دخول المحررين» (تسجيل تنفيذ مع الصور، إضافة برنامج غير مدرج، حذف تنفيذ، حذف برنامج غير مدرج).
- **مشاركة فورية:** ما يضيفه أي محرر يظهر لكل الزوار مباشرة.
- **لوحة المنسق (`#admin`):** مؤشرات وإنفوجرافيك، تنبيهات البرامج المتأخرة والمتعثرة مع سبب التعثر، الاعتماد، التوثيق، وإدارة البرامج حسب الخطة أو الأسبوع أو المجال أو المنفذ.
- **أيقونات المحررين أعلى الموقع:** «المستخدمون» (`#admin-people`) لتحرير أسماء المنفذين ومهامهم وصورهم داخل الجدول، و«إدارة الخطة» (`#admin-plans`) لتحرير برامج كل خطة وإضافة برامج جديدة.
- **صفحات الخطط (`#plans`):** صفحة تعريفية لكل خطة (المسؤول، عدد البرامج، نسبة الإنجاز، البرامج)، مع إرفاق ملف الخطة PDF من نموذج إضافة الخطة أو تعديلها، ويُحفظ في مخزن الملفات نفسه للاطلاع والتنزيل.

صنع بذكاء أ/ عبدالعزيز يوسف المديني

## الخطوة 1: إنشاء قاعدة البيانات (Supabase — مجاني)

1. أنشئ حسابًا في supabase.com، ثم **New project** (اختر أقرب منطقة، واحفظ كلمة مرور قاعدة البيانات في مكان آمن).
2. من القائمة الجانبية افتح **SQL Editor ← New query**، والصق محتوى الملف `supabase-setup.sql` كاملًا، ثم **Run**.
3. **أوقف التسجيل العام** حتى لا يُنشئ أحد حسابًا لنفسه:
   **Authentication ← Sign In / Providers ← Email**، وأطفئ **Allow new users to sign up**.
4. **أنشئ حسابات المحررين:** **Authentication ← Users ← Add user ← Create new user**
   (بريد وكلمة مرور لكل محرر، وفعّل **Auto Confirm User**).
5. انسخ بيانات الربط من **Project Settings ← API**:
   - **Project URL**
   - مفتاح **anon public**

## الخطوة 2: ربط الموقع

افتح الملف `assets/config.js` والصق القيمتين:

```js
window.SMART_PLANS_CONFIG = {
  supabaseUrl: 'https://xxxx.supabase.co',
  supabaseAnonKey: 'eyJhbGciOi...',
  bucket: 'evidence'
};
```

مفتاح **anon** عام ومصمم للنشر في المواقع؛ الحماية تأتي من سياسات الصلاحيات في ملف الإعداد.
لا تضع أبدًا مفتاح **service_role** في هذا الملف.

## الخطوة 3: النشر على GitHub Pages

1. أنشئ مستودعًا عامًا (Public) على github.com.
2. **Add file ← Upload files**، وارفع **محتويات** هذا المجلد (ومنها مجلد `assets`)، ثم **Commit changes**.
3. **Settings ← Pages**: اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة أو اثنتين يظهر الرابط: `https://اسم-حسابك.github.io/اسم-المستودع/`

يمكنك أيضًا تعديل `assets/config.js` لاحقًا من GitHub مباشرة (افتح الملف ← أيقونة القلم ← Commit).

## ملفات المستودع

| الملف | الغرض |
|---|---|
| `index.html` | الموقع كاملًا |
| `404.html` | نسخة من الصفحة الرئيسية لأي رابط خاطئ |
| `assets/config.js` | بيانات الربط بـ Supabase |
| `assets/store.js` | الحفظ المشترك وتسجيل الدخول |
| `assets/coordinator.js` | لوحة المنسق وصفحتا المستخدمين وإدارة الخطة (تعديلاتها تُحفظ في جدول السجلات نفسه بعلامة `kind: coordinator` وتُطبَّق فوق بيانات الخطة؛ لا تحتاج تعديلًا على قاعدة البيانات) |
| `assets/coordinator.css` | تنسيقات لوحة المنسق |
| `assets/plans.js` | صفحات الخطط التعريفية (`#plans` و`#plan-<رقم>`): المسؤول وعدد البرامج والإنجاز وملف الخطة PDF |
| `assets/plans.css` | تنسيقات صفحات الخطط ووسم الخطة على بطاقات البرامج |
| `assets/pdfjs/` | مكتبة pdf.js (Mozilla، رخصة Apache 2.0) لعرض صفحات ملف الخطة داخل الموقع |
| `supabase-setup.sql` | إعداد الجدول والصلاحيات ومخزن الصور (يُشغَّل مرة واحدة) |
| `.nojekyll` | يمنع GitHub من معالجة الملفات بـ Jekyll |

## ملاحظات

- قبل تعبئة `config.js` يعمل الموقع في **وضع تجريبي** يحفظ في المتصفح فقط، وتظهر عبارة تنبيه في التذييل.
- المساعد الذكي (الإملاء الصوتي) يعمل داخل Claude فقط؛ نموذج الإدخال اليدوي متاح كاملًا.
- الخطة المجانية في Supabase تتسع لـ 500MB بيانات و1GB صور، وهذا كافٍ لعام دراسي كامل مع الصور المصغّرة.
- إذا لم يُستخدم المشروع المجاني أسبوعًا كاملًا قد يوقفه Supabase مؤقتًا؛ يُعاد تشغيله بضغطة من لوحة التحكم.
